# Rymoo – Clothing Website

## 📌 Project Overview

Rymoo is a modern and responsive clothing website designed to showcase fashion products in an attractive and user-friendly way. The project focuses on clean UI, responsiveness, and dynamic product handling.

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Bootstrap
* JSON (for product data)

## ✨ Features

* Responsive layout for mobile, tablet, and desktop
* Dynamic product listing using JSON
* Clean and modern UI design
* Interactive elements and hover effects
* Easy navigation between sections

## 📂 Project Structure

* index.html – Main webpage
* css/ – Styling files
* js/ – JavaScript logic and JSON handling
* assets/ – Images and media files

## 🚀 How to Run

Simply open the `index.html` file in any modern web browser.
